# Портфолио Java-разработчика

Это современный одностраничный сайт-портфолио, созданный для демонстрации проектов. Он полностью адаптивен и поддерживает светлую, темную и системную темы.

## ✨ Особенности

- **Современный дизайн (2025-2026):** Чистый интерфейс с плавными анимациями (Framer Motion) и продуманной типографикой.
- **Адаптивный дизайн:** Корректно отображается на всех устройствах, от мобильных телефонов до настольных компьютеров.
- **Переключатель тем:** Поддержка светлой, темной и автоматической (системной) тем.
- **Docker Ready:** Готовые конфигурации для Docker и Nginx.
- **CI/CD:** Настроенный GitHub Workflow для автоматической сборки Docker-образа.

## 🛠️ Технологии

- **React 19**
- **TypeScript** (Strict Mode)
- **Vite**
- **Tailwind CSS 4**
- **Framer Motion** (для анимаций)
- **Lucide React** (для иконок)
- **Docker & Nginx**

## 🚀 Как использовать

### Локальная разработка
1. Установите зависимости: `npm install`
2. Запустите сервер для разработки: `npm run dev`

### Сборка
Выполните `npm run build`, результат будет в директории `build/`.

### Docker
Сборка образа:
```bash
docker build -t megoru-portfolio .
```
Запуск контейнера:
```bash
docker run -p 80:80 megoru-portfolio
```
